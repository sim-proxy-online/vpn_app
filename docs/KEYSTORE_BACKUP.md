# Бэкап ключа подписи APK — почему, где и как

## Почему это критично

`android/release.keystore` подписывает **все** релизы APK. Android запрещает
установку обновления поверх приложения с другим сертификатом подписи.

**Потеря keystore = точка невозврата:** все установленные приложения у пользователей
нельзя обновить — только удалить и переустановить (пользователи потеряют профили).
Восстановить ключ невозможно, выпустить «тот же» — тоже.

## Что лежит в бэкапе

| Файл | Зачем |
|---|---|
| `release.keystore` | сам ключ подписи |
| `keystore.properties` | пароли/алиасы к нему (без них keystore бесполезен) |

## Где лежат копии (2 места, разные физические диски/носители)

1. `D:\111\keystore-backup\keystore-<дата>.enc`
2. `C:\Users\<вы>\Documents\SimProxy-keystore-backup\keystore-<дата>.enc`

⚠️ Обе копии на одном компьютере — это страховка от сбоя диска, но **не** от его
потери/кражи. Скопируйте `.enc` ещё и на флешку/внешний диск/облачное хранилище.

## Формат

Контейнер `SKB1`: AES-256-CBC, ключ из PBKDF2-SHA256 (200 000 итераций, случайный
salt), подпись Encrypt-then-MAC (HMAC-SHA256) — подделка или порча файла отклоняются
до расшифровки. Пароль-фраза генерировалась случайно и НЕ хранится рядом с файлами:
она должна лежать в вашем менеджере паролей. **Нет фразы — нет бэкапа.**

## Команды

```powershell
# Новый бэкап (после любой смены ключа/паролей):
.\scripts\backup-keystore.ps1 -Passphrase '...'

# Проверка, что бэкап читается (в пустую папку!):
.\scripts\backup-keystore.ps1 -Passphrase '...' -Restore -InFile <файл.enc> -OutDir .\check

# Сверка:
Get-FileHash .\check\release.keystore -Algorithm SHA256
```

Восстановление на живой `android/` скрипт сам блокирует, если файл уже существует —
намеренно, чтобы не затереть рабочий ключ.

## Чек-лист после каждой смены ключа

- [ ] `scripts\backup-keystore.ps1` запущен, `.enc` лежит в обоих местах
- [ ] фраза сохранена в менеджере паролей (и только там)
- [ ] восстановление проверено на копию (`-OutDir` в пустую папку)
- [ ] `.enc` продублирован на носитель вне этого компьютера
